# Troubleshooting

- **source_busy/source_changed:** close every source writer; inspect failed capture evidence and retry into new paths. Do not kill unknown processes automatically.
- **tool_missing/tool_integrity:** reinstall the complete verified distribution. Do not replace tools through PATH.
- **key_missing/trust_failed:** use the matching separately stored recovery keys and intended trust file. Do not trust a replacement key obtained from the archive.
- **unsafe_destination/conflict:** choose new independent paths, existing parents and nonoverlapping project mappings. Existing data is never merged.
- **unsupported_filesystem:** shorten roots below the checked path budget or remove unsupported reparse/path state from the selected scope. Do not rename original evidence silently.
- **git_unsupported:** unsupported repository state is refused. Preserve it separately; do not flatten or fetch objects automatically to manufacture compatibility.
- **insufficient_space:** choose adequate local capacity. The safety reserve is intentional.
- **changed / exit 5:** preserve later work. Compare the report against archive-bound state; rollback must not discard changes.
- **failed operation:** retain protected evidence and read [recovery instructions](operator-runbook.md). No completed result is implied by existing partial files.

Do not attach private archives, keys, conversations or raw diagnostics to public issues. Use synthetic reproductions and safe error codes.
