# Public-data boundary

Only exact allowlisted source, synthetic tests and portable documentation belong in the repository. Private checkpoints, historical reports, recovery keys, archives, real conversations, workstation profiles and generated fixtures remain outside it. `.gitignore` is defense in depth; exact index/package membership and canary/secret audits are mandatory.

Check final Git author metadata and source/history/package contents before publication. Keep All rights reserved licensing unless company ownership approves a change. Binary redistribution includes CPython, Python dependencies, age/Minisign and MinGit component notices. Company approval is separate from technical GO; unsigned artifacts must remain labeled unsigned.

No validation or packaging tool pushes, tags, uploads or publishes.
